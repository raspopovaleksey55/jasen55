# Сайт ОРОО «ЦПОИ «Ясень»

Статический сайт организации: восемь страниц, один файл стилей, без внешних библиотек и чужих
скриптов. Публикуется на GitHub Pages прямо из этого репозитория.

**Адрес сайта:** https://rasopovaleksey55.github.io/jasen55/

## Страницы

| Файл | Что на странице |
|---|---|
| `index.html` | Главная: чем занимаемся, цифры, последние проекты, ссылки на соцсети |
| `o-nas.html` | Об организации: цели, направления, история с 2005 года, краткие сведения |
| `proekty.html` | Девять реализованных проектов: даты, суммы, результаты, галерея |
| `otchety.html` | Показатели деятельности и годовые отчёты (файлы PDF) |
| `upravlenie.html` | Орган управления, руководитель, команда по ролям, добровольцы |
| `partnery.html` | Партнёры: власть, музеи и вузы, клубы, информационные партнёры |
| `pressa.html` | Публикации в СМИ и видеоматериалы |
| `kontakty.html` | Контакты и реквизиты организации |
| `style.css` | Оформление всех страниц |
| `img/` | Фотографии |
| `otchety/` | PDF годовых отчётов |

## Как обновлять

Файлы правятся на компьютере, изменение фиксируется коммитом — через минуту-другую GitHub Pages
публикует новую версию. Компилировать и загружать архив куда-либо не нужно.

**Фотографии** кладутся в `img` строго с такими именами:

| Имя файла | Что на фото |
|---|---|
| `fest-1.jpg` | фестиваль «Щит Сибири», общий вид площадки |
| `fest-2.jpg` | турнир по историческому фехтованию |
| `lager.jpg` | лагерь живой истории |
| `kvest.jpg` | исторический квест |
| `master.jpg` | мастерская «Умелец» |
| `shkola.jpg` | школа юного реконструктора |
| `logo.jpg` | логотип организации в шапке всех страниц |

Сейчас на месте снимков стоят серые заглушки тех же размеров (1200×800) с подписью, что там должно
быть. Достаточно положить настоящие снимки с теми же именами — править код не нужно. Требования:
ширина 1200–1600 точек, вес до 300 КБ, формат `.jpg`.

**Годовые отчёты** кладутся в папку `otchety` под именами `otchet-2025.pdf`, `otchet-2024.pdf`,
`otchet-2023.pdf`. Пока файлов нет, на странице «Отчёты» стоит пометка «готовится к публикации»,
битых ссылок нет.

## Публикация

- Источник: ветка `main`, корень репозитория.
- Файл `.nojekyll` отключает обработку сайта через Jekyll — страницы отдаются как есть.
- Свой домен подключается позже: файл `CNAME` с именем домена плюс записи в DNS у регистратора;
  сертификат HTTPS на GitHub Pages выдаётся бесплатно.
